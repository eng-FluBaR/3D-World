## ❓ Ако все още има проблем:

### Проблем: Името не се показва
**Решение:**
1. Отворете Console (F12)
2. Проверете дали има červени грешки
3. Проверете дали се показва: `[NAV] User info: {role: "...", name: "..."}`
4. Ако `userInfo` е `null` → излезте и влезте отново

### Проблем: Качването не работи
**Решение:**
1. Проверете Console (F12) за грешки
2. Ако виждате `400 Bad Request` → презаредете с Ctrl+F5
3. Ако виждате `403 Forbidden` → излезте и влезте отново (за да обновите session)

### Проблем: Вход/Регистрация все още се виждат
**Решение:**
1. Натиснете **Ctrl + F5** за hard refresh
2. Изчистете browser cache: Settings → Privacy → Clear browsing data
3. Опитайте в режим Incognito
